How It Works

From a one-line idea to a finished comic in five steps.

  1. Plan the story Google Gemini turns your idea into a comic title, a description of the main character, and a panel-by-panel outline.
  2. Write the script A second Gemini call writes the narration captions and speech-bubble dialogue for every panel.
  3. Draw the art FLUX.1 draws each panel, running on a free Hugging Face Space. Panels are drawn in parallel to save time. If a service is busy or out of free quota, the next one takes over: Stable Diffusion 3 on Hugging Face, then Pollinations.ai, then AI Horde. The character description is repeated in every prompt so they look the same throughout.
  4. Lay out the comic The images and text are combined into panels for the web preview.
  5. Export to PDF fpdf2 builds a printable PDF with a cover page and one page per panel.

Tech stack

  • Backend: Python, FastAPI, Uvicorn
  • AI text: Google Gemini (google-genai SDK)
  • AI images: FLUX.1-schnell, Stable Diffusion 3, Pollinations.ai and AI Horde, with automatic fallback
  • PDF: fpdf2 + Pillow
  • Frontend: Jinja2 templates, HTML and CSS
